# Changelog

[GitHub Releases](https://github.com/bhouston/tanstack-router-ga4/releases) is the cumulative, automatically generated release history. Each automated release also includes a generated `CHANGELOG.md` in the npm package and as a downloadable release asset for that release.

Versions are computed from Conventional Commits: `fix` → patch, `feat` → minor, and breaking changes → major. Development-only changes do not trigger a release. Historical manual releases were not retroactively reconstructed.
