# Security policy

Security fixes are provided for the latest published version of `tanstack-router-ga4`. Upgrade older versions before reporting a suspected vulnerability.

Report suspected vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/bhouston/tanstack-router-ga4/security/advisories/new). If that option is unavailable, contact the maintainer through [ben3d.ca](https://ben3d.ca) to arrange a private report. Do not disclose vulnerabilities, credentials, or sensitive analytics data in public issues.

Include affected versions, reproduction steps, impact, and any suggested mitigation. The maintainer will coordinate a fix and disclosure with the reporter; no fixed response time is promised.
